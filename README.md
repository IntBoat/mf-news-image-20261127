A Python program that draws a one-page newspaper front page summing up the world news of Friday 27 November 2026 and writes it to /output/entry.png.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program uses only the Python standard library: it rasterises the front page with a built-in 5x7 bitmap font and encodes the PNG by hand, so it runs with no network and writes byte-identical output on every run. The five stories on the page are the EU budget deadlock, the Thanksgiving storm cutting power, Zelensky warning of a new mass strike, Trump calling the GDP figures fake, and the Delhi cyber-slavery raid. Run it twice and compare the two files: they are identical.
